October 22 fixes

Compatibility and rollout
Use Node 24.13 or newer. npm ci prepares locked local OCR/barcode assets; serve the source dist directory with serve.mjs. Household sync is disabled by default. Back up its SQLite data while stopped before rollout and preserve membership keys privately.
Run npm run build:android to prepare/sync the separate native asset copy. ANDROID_BUILD.txt covers Java/JDK 21, the Android SDK, debug builds and signed bundles. PLAY_STORE_GUIDE.txt covers account creation, current Play requirements and listing/testing steps.

Physical-device testing, actual native share/print/picker behavior, upgrades and the signed build's network/permission audit remain required. Android selects existing photos; direct camera capture is not implemented.
The privacy page remains a draft. Complete publisher/contact/country/audience choices, host a final public policy, prepare store assets, verify the account and complete applicable Play testing/declarations before submission. Review the components compiled into OCR Wasm and the resolved native/Maven libraries and licenses. The new Expo app has separate unpatched upstream tooling advisories tracked in its release notes.
Public web hosting and live FX remain deployment checks. Web OCR vendor files are not cached for offline capture; Android packages them locally. Rollback must preserve local comparison files and any household database. No production service or database was changed.

The legacy web/Capacitor OCR build pins libwebp 1.2.2 at 20ef03ee351d4ff03fc5ff3ec4804a879d1b9d5c in tesseract.js-core 7.0.0, within the affected range for CVE-2023-4863 (https://nvd.nist.gov/vuln/detail/CVE-2023-4863). The current capture path decodes uploads in the browser, draws a new canvas, and sends its PNG encoding to OCR; raw uploaded WebP does not reach that Wasm decoder through this path. No exploitable app path was established in this review. Updating/rebuilding the native OCR dependencies remains a maintenance item; preserve this boundary when adding capture paths. The new React Native app does not include this OCR bundle.
